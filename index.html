Built a sentiment analysis project comparing TextBlob and VADER on positive and negative text samples to evaluate how each tool performs on polarity classification.

  • TextBlob: 97.1% positive accuracy • 22.9% negative accuracy
  • VADER: 82.6% positive accuracy • 44.4% negative accuracy
